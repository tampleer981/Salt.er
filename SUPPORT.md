# Support

- **Questions:** open an [issue](https://github.com/tampleer981/salt.er/issues/new/choose)
  with the question form.
- **Ideas:** open an [issue](https://github.com/tampleer981/salt.er/issues/new/choose)
  with the feature request form.
- **Bugs:** open an [issue](https://github.com/tampleer981/salt.er/issues/new/choose)
  with the bug report form. Include your Salt.er and Windows versions and the
  relevant lines from `%LOCALAPPDATA%\Salt.er\logs`.
- **Security problems:** do not use issues; follow [SECURITY.md](SECURITY.md).

Wallpaper content, availability, and rate limits are controlled by
[wallhaven.cc](https://wallhaven.cc), not by this project.
