# Architecture decision records

Significant decisions are recorded here in the
[MADR 4](https://adr.github.io/madr/) format. An ADR is not edited once
accepted; a later ADR supersedes it and the old one's status is updated.

To add one, copy the structure of an existing record, use the next number, and
add it to the index.

| ADR | Title | Status |
| --- | --- | --- |

| [0002](0002-use-wallhaven-as-source.md) | Use wallhaven as the only wallpaper source | Accepted |
| [0003](0003-unsigned-unpackaged-distribution.md) | Distribute unsigned, unpackaged builds with Velopack | Accepted |
